# Changelog

## 1.0.0 – first public release

- Date for a whole film or single frames (day, month or year), times count up per frame
- Approximate dates: reduced-precision XMP date + configurable keyword ("circa")
- "From here +1 day", times follow drag & drop order
- Place search via OpenStreetMap Nominatim, recently used places, show on map, reverse lookup
- Lossless rotation (EXIF orientation), star ratings, rejects
- Film info: photographer, rights, IPTC Digital Source Type
- JPEG copies via ImageMagick (parallel, colour profile and metadata kept, rotation applied)
- Archive overview: recursive scan for missing metadata
- Right-click menu for selected frames (own date/location for part of a film)
- Undo, confirmation table, backup clean-up
- Portable mode, German/English UI
